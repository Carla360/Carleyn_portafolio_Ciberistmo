# Portafolio de Carleyn Miranda

## Publicarlo en GitHub Pages
1. Entra a https://github.com e inicia sesión.
2. Crea un repositorio nuevo y selecciona **Public**.
3. Sube el archivo `index.html` de esta carpeta.
4. Abre **Settings → Pages**.
5. En **Build and deployment**, selecciona **Deploy from a branch**.
6. Selecciona la rama `main` y la carpeta `/(root)`, y pulsa **Save**.
7. Espera unos minutos y abre el enlace que aparece en GitHub Pages.

El archivo `index.html` contiene el diseño, los estilos y el JavaScript; no necesita carpetas adicionales.
